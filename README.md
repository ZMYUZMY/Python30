## 🚀 快速开始

### 环境要求
- **Python 3.12+**（部分 f-string 嵌套引号写法需 3.12 及以上版本）

### 运行方式

每个文件都可以独立运行，在项目目录下执行：

```bash
python 1_name.py
```

按数字顺序逐个学习即可，每个文件都带有中文注释。

## 🎯 综合项目：命令行记账本

学习完所有知识点后，`项目一：命令行记账本.py` 将所学内容融会贯通，实现了一个完整的小程序：

- ✅ **读写 JSON 文件** —— 数据持久化，重启不丢失
- ✅ **异常处理** —— 文件不存在时自动创建
- ✅ **列表 + 字典** —— 存储每条账目 `{'金额': ..., '备注': ...}`
- ✅ **循环 + enumerate** —— 逐条打印明细
- ✅ **sum / max + lambda** —— 统计合计与最贵一笔

运行效果示例：

```
1,午饭:12.5元
2,奶茶:11元
3,聚餐:56元
共3笔，合计79.5元
最贵的一笔:聚餐56
```

## 💡 知识点速查

- **f-string**：`f"{name}"` 格式化字符串
- **类型转换**：`int()`、`float()`、`str()`
- **文件读写**：`open()` + `with` 语句，`'r'`/`'w'`/`'a'` 模式
- **列表**：靠位置访问，用下标 `[i]`
- **字典**：靠键访问，用 `d['key']`，`get()` 可设默认值
- **元组**：创建后不可修改
- **集合**：自动去重、无序
- **类**：`__init__` 挂属性，方法第一个参数是 `self`
- **继承**：子类自动拥有父类方法，可用 `super()` 调用父类
